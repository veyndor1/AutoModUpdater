# Repository settings

Verified on 16 October 2026.

- Repository: `veyndor1/AutoModUpdater`, public by the owner's explicit choice.
- Default and initially published branch: `1.20.1`.
- The owner `veyndor1` is the only collaborator with write access. Other users cannot
  push or create branches without an explicit access grant.
- Branch protection is enabled for `1.20.1`, including enforcement for the owner.
  Force-push and branch deletion are disabled. Direct owner commits remain permitted;
  pull requests and external reviews are not required.
- The earlier HTTP 403 restriction applied while the repository was private. With
  the current public visibility, the previously approved protection could be enabled.
- GitHub vulnerability alerts are enabled. This does not imply that code scanning
  or every paid security feature is enabled.
- Releases contain compiled, obfuscated complete updater builds and companion
  licenses/checksums for the owner's `mcmods2` pack. The same pack-player build is
  distributed from `veyndor1/mcmods2`; it is not a general-purpose updater service.
- Commits use the owner's GitHub noreply identity. No additional contributors or
  assistant co-authors are added by the publication process.

`mcmods2` is the owner's Minecraft 1.20.1 mod/config publication feed and retains
its `main` branch. Publishing rights belong to the owner; pack players only need
download access. Documentation edits do not change its active pack manifest.

`mc-mods` targets Minecraft 1.12.2. It is not part of this updater's distribution
or compatibility scope. No changes to that repository are included in this work.
